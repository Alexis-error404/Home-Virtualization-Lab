# Virtual Networking

## Objective
Demonstrate how VM connectivity changes across network modes.

## Exercises
- Identify VM IP/subnet/gateway/DNS
- Test VM-to-VM communication
- Test host-to-VM communication
- Test Internet access when intended
- Document NAT vs host-only vs bridged behavior
- If using multiple virtual networks, document routing/trust boundaries

## Tools
`ping`, `ipconfig`, `ip addr`, `route print`, `ip route`, `nslookup`.

## Evidence
Capture network configuration and successful connectivity tests.
