# Monitoring & Troubleshooting

## Monitor
CPU, memory, disk capacity, VM responsiveness, network connectivity, guest service health, and host resource pressure.

## Troubleshooting Order
1. Physical host resources
2. Hypervisor/VM state
3. Virtual NIC/network
4. Guest IP configuration
5. DNS
6. Guest services/application

Document symptoms, hypothesis, test, result, fix, and validation.

## Evidence
Capture one real lab troubleshooting example from symptom through resolution.
