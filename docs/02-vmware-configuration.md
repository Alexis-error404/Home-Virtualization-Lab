# VMware Configuration

## Build
1. Install/update VMware.
2. Review virtual-network configuration.
3. Create VM templates or standardized VM settings.
4. Configure CPU, memory, disk, firmware, NIC, and ISO.
5. Install guest tools where appropriate.

## Validation
Confirm each VM boots, sees expected virtual hardware, and is connected to the intended virtual network.

## Evidence
Capture virtual-network settings and VM hardware configuration.
