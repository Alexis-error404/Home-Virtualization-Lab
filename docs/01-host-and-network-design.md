# Host & Network Design

## Objective
Plan a multi-VM environment before deployment.

## Inventory
Document physical CPU, RAM, storage, host OS, hypervisor, and available network connectivity.

## Capacity Plan
Estimate resources for each VM and leave headroom for the host.

Example roles:
- Windows Server
- Windows client
- Linux server
- optional security/monitoring VM

## Network Plan
Choose NAT, host-only, bridged, or multiple virtual networks based on the lab objective. Document trust boundaries and subnets.

## Evidence
Capture sanitized host specifications and a network diagram.
