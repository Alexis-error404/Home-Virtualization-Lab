# Snapshots & Recovery

## Objective
Practice safe change testing and rollback.

## Exercise
1. Establish a known-good VM.
2. Create a snapshot before a controlled configuration change.
3. Make the change.
4. Validate its effect.
5. Revert when appropriate.
6. Verify the VM returns to the expected state.

## Important
Snapshots are useful for lab rollback but are not a substitute for independent backups.

## Evidence
Capture snapshot manager before/after and validation of restored state.
